#  Spotify Song Popularity Prediction

This project predicts the **popularity of songs on Spotify using machine learning techniques**.  
It analyzes different audio features such as danceability, energy, tempo, loudness, and more to determine how likely a song is to become popular. :contentReference[oaicite:0]{index=0}

##  Project Overview
The project uses a Spotify dataset containing song metadata and audio features.  
Machine learning models are applied to analyze patterns and predict a song's popularity score.

- Python  
- Pandas & NumPy  
- Scikit-learn  
- Matplotlib / Seaborn  
- Google Colab

##  Features
- Data preprocessing and analysis  
- Feature visualization  
- Machine learning model training  
- Song popularity prediction
